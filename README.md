# Algorand Crowdfunding

## Project Overview

Algorand Crowdfunding is a decentralized crowdfunding application
built using the Algorand blockchain.

The project aims to provide a transparent and secure platform where
users can create crowdfunding campaigns and contribute funds using
blockchain technology.

## Project Goals

- Create a decentralized crowdfunding platform.
- Use the Algorand blockchain for transactions.
- Provide transparency for campaign contributions.
- Allow users to participate in crowdfunding campaigns.
- Learn and apply Algorand development concepts.

## Technologies

- Algorand
- Blockchain
- Smart Contracts
- JavaScript
- React

This project is currently under development as part of my Algorand course.
